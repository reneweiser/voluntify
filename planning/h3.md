# Plan: Tests for 8 Untested Actions

## Context

8 Actions have zero direct test coverage. The gaps are concentrated in destructive operations (`PermanentlyDeleteEvent`, `PermanentlyDeleteProject`), the invitation flow (`InviteMember`), Fortify registration/reset (`CreateNewUser`, `ResetUserPassword`), and utility actions (`CreateAdminWithOrganization`, `ExportGearSummaryCsv`, `SendTestEmail`). `SendTestEmail` has indirect mock coverage in `EmailSettingsTest` but no direct test.

---

## Actions and Test Plans

### 1. PermanentlyDeleteEvent (`app/Actions/PermanentlyDeleteEvent.php`)

**What it does:** Deletes title image from storage, then hard-deletes the event (cascades handle related records).

**Test file:** `tests/Feature/Actions/PermanentlyDeleteEventTest.php`

```
it('permanently deletes the event from the database')
it('deletes the title image from storage when present')
it('succeeds when event has no title image')
it('cascades deletion to jobs, shifts, and signups')
```

**Setup:** `Storage::fake('public')`, `Event::factory()` with related jobs/shifts/signups.

---

### 2. PermanentlyDeleteProject (`app/Actions/PermanentlyDeleteProject.php`)

**What it does:** Captures project name + orphaned event names, deletes title image, hard-deletes project, dispatches `ProjectDeletedActivity` if authenticated.

**Test file:** `tests/Feature/Actions/PermanentlyDeleteProjectTest.php`

```
it('permanently deletes the project from the database')
it('deletes the title image from storage when present')
it('succeeds when project has no title image')
it('cascades deletion to related events')
it('dispatches activity event with correct data when authenticated')
it('skips activity event when not authenticated')
it('captures orphaned event names before deletion')
```

**Setup:** `Storage::fake('public')`, `Event::fake()`, `Project::factory()` with events.

---

### 3. InviteMember (`app/Actions/InviteMember.php`)

**What it does:** Creates new user (if needed) with random password + personal org, attaches to org with role, sends appropriate notification, dispatches `MemberInvited` event.

**Test file:** `tests/Feature/Actions/InviteMemberTest.php`

```
it('creates a new user and attaches to organization')
it('sends staff invitation to new user with password')
it('creates personal organization for new user')
it('sets must_change_password for new user')
it('attaches existing user to organization with role')
it('sends added-to-organization notification to existing user')
it('does not send staff invitation to existing user')
it('throws MemberAlreadyExistsException for duplicate member')
it('dispatches MemberInvited event when authenticated')
it('skips event dispatch when not authenticated')
```

**Setup:** `Notification::fake()`, `Event::fake()`, `Organization::factory()`, `User::factory()`.

---

### 4. CreateAdminWithOrganization (`app/Actions/CreateAdminWithOrganization.php`)

**What it does:** Creates user + organization in transaction, attaches as Organizer, pre-verifies email.

**Test file:** `tests/Feature/Actions/CreateAdminWithOrganizationTest.php`

```
it('creates user and organization with organizer role')
it('sets email as verified')
it('does not require password change')
it('generates unique slug for organization')
it('throws DomainException for duplicate email')
```

**Setup:** `Organization::factory()` (for slug collision test), direct action invocation.

---

### 5. CreateNewUser (`app/Actions/Fortify/CreateNewUserTest.php`)

**What it does:** Fortify registration — validates input, creates user + personal org in transaction. Implements `CreatesNewUsers`.

**Test file:** `tests/Feature/Actions/Fortify/CreateNewUserTest.php`

```
it('creates user with valid input')
it('creates personal organization for new user')
it('rejects missing name')
it('rejects duplicate email')
it('rejects weak password')
it('rejects unconfirmed password')
it('hashes the password')
```

**Setup:** Direct `(new CreateNewUser)->create([...])` calls. Uses `password_confirmation` field.

---

### 6. ResetUserPassword (`app/Actions/Fortify/ResetUserPasswordTest.php`)

**What it does:** Fortify password reset — validates + updates password via `forceFill`. Implements `ResetsUserPasswords`.

**Test file:** `tests/Feature/Actions/Fortify/ResetUserPasswordTest.php`

```
it('resets password with valid input')
it('hashes the new password')
it('rejects unconfirmed password')
it('rejects weak password')
it('does not modify other user attributes')
```

**Setup:** `User::factory()->create()`, direct `(new ResetUserPassword)->reset($user, [...])` calls.

---

### 7. ExportGearSummaryCsv (`app/Actions/ExportGearSummaryCsv.php`)

**What it does:** Returns `LazyCollection` with German CSV header + gear records (volunteer name, email, item, size, pickup status).

**Test file:** `tests/Feature/Actions/ExportGearSummaryCsvTest.php`

```
it('returns header row for project with no gear')
it('exports gear records with correct columns')
it('shows size when present and empty when null')
it('shows Ja for picked up and Nein for not picked up')
it('only exports gear for the specified project')
```

**Setup:** `Project::factory()` with `ProjectGearItem`, `Volunteer`, `VolunteerGear` factories.

---

### 8. SendTestEmail (`app/Actions/SendTestEmail.php`)

**What it does:** Sends test email via org-specific or default mailer. Uses `OrganizationMailerService` for mailer resolution.

**Test file:** `tests/Feature/Actions/SendTestEmailTest.php`

```
it('sends test email to recipient with correct subject')
it('uses organization SMTP from address when configured')
it('falls back to default from address when org SMTP not set')
it('includes organization name in email body')
```

**Setup:** `Mail::fake()`, `Organization::factory()->create(['smtp_from_address' => '...'])`. Mock `OrganizationMailerService` or use real service with fake mailer.

---

## Execution Order (by risk priority)

1. `PermanentlyDeleteEvent` + `PermanentlyDeleteProject` (destructive operations)
2. `InviteMember` (complex multi-path flow)
3. `CreateNewUser` + `ResetUserPassword` (Fortify auth)
4. `CreateAdminWithOrganization` (setup utility)
5. `ExportGearSummaryCsv` (read-only)
6. `SendTestEmail` (already has indirect coverage)

## Verification

After each test file:
```bash
vendor/bin/sail artisan test --compact --filter=TestName
```

After all:
```bash
vendor/bin/sail artisan test --compact
vendor/bin/sail bin pint --dirty --format agent
```

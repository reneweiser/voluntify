# Plan: Replace `auth()->user()` with explicit `User $causer` in Actions

## Context

22 Action classes use `auth()->user()` for optional audit-trail event dispatch. The pattern is uniform:
```php
if (auth()->user()) {
    SomeActivityEvent::dispatch($model, auth()->user());
}
```
This hides a dependency, prevents testing event dispatch, and scatters the audit concern across 22 files. The decision: replace with an explicit **non-nullable** `User $causer` parameter (nullable only for 2 console-called Actions). This eliminates the conditional, guarantees audit trail completeness, and enables `Event::assertDispatched()` in tests.

---

## Batch Structure (4 batches, each leaves tests green)

### Batch 1: 17 Livewire-only Actions (mechanical)

Each Action gets the same transformation:

**Action change:**
1. Add `User $causer` as the **last** parameter of `execute()`
2. Remove `if (auth()->user()) { ... }` conditional
3. Replace `auth()->user()` with `$causer` in event dispatch

**Livewire caller change:** Append `causer: auth()->user()` to each `execute()` call.

**Test change:** Add `$this->user = User::factory()->create()` in `beforeEach()`, pass `causer: $this->user` to all `execute()` calls, add one event dispatch assertion per Action.

### Batch 2: CloneEvent + CloneProject (parameter threading)

**Risk: positional arguments.** Both have optional params before where `$causer` needs to go.

**CloneEvent** — current: `execute(Event $event, ?int $targetProjectId = null, ?int $dateOffsetDays = null)`
- New: `execute(Event $event, User $causer, ?int $targetProjectId = null, ?int $dateOffsetDays = null)`
- `$causer` goes second (before optionals). Safe because:
  - `EventShow:173` uses named arg: `$action->execute($this->event, dateOffsetDays: $offset)` → add `causer: auth()->user()`
  - `CloneProject:34` uses positional: `$this->cloneEvent->execute($event, $clonedProject->id, $dateOffsetDays)` → convert to named args

**CloneProject** — current: `execute(Project $project, ?int $dateOffsetDays = null)`
- New: `execute(Project $project, User $causer, ?int $dateOffsetDays = null)`
- `CloneProject` itself doesn't dispatch events but must thread `$causer` to `CloneEvent`
- `ProjectShow:238` uses positional: `$action->execute($this->project, $offset)` → convert to named args

**Updated call sites:**
```php
// CloneProject line 34 (calling CloneEvent):
$this->cloneEvent->execute($event, causer: $causer, targetProjectId: $clonedProject->id, dateOffsetDays: $dateOffsetDays);

// EventShow line 173 (calling CloneEvent):
$clonedEvent = $action->execute($this->event, causer: auth()->user(), dateOffsetDays: $offset);

// ProjectShow line 238 (calling CloneProject):
$clonedProject = $action->execute($this->project, causer: auth()->user(), dateOffsetDays: $offset);
```

**Tests:** `CloneEventTest` has 14 tests using `$action->execute($this->event)` — add `$this->user` + pass as second arg. `CloneProjectTest` similar.

### Batch 3: RequestEventDeletion + RequestProjectDeletion (password check)

Different pattern — `auth()->user()->password` for verification, not event dispatch.

**Action change:** Add `User $causer` parameter, replace `auth()->user()->password` with `$causer->password`.
```php
// Before:
if (! Hash::check($password, auth()->user()->password)) {
// After:
if (! Hash::check($password, $causer->password)) {
```

**Livewire callers:**
- `EventShow::requestDeletion()` — add `causer: auth()->user()`
- `ProjectShow::requestDeletion()` — add `causer: auth()->user()`

**Tests:** These already use `actingAs($this->user)`. Update `execute()` calls to pass `$this->user`. The `actingAs()` can be removed from the Action test (only needed for Livewire tests).

### Batch 4: PermanentlyDeleteProject + InviteMember (nullable — console commands)

These 2 Actions are called from artisan commands without auth context.

**Signature:** `?User $causer = null` as the **last** parameter.
**Conditional:** `if (auth()->user())` → `if ($causer)` (same semantics as today).

**PermanentlyDeleteProject:** `execute(Project $project, ?User $causer = null): void`
- `PurgePendingDeletionsCommand` passes no user → null default → event skipped (unchanged behavior)

**InviteMember:** `execute(Organization $org, string $name, string $email, StaffRole $role, ?User $causer = null): User`
- `MemberManagement` (Livewire) → add `causer: auth()->user()`
- `InviteOrganizerCommand` → passes no user → null default → event skipped (unchanged behavior)

**Tests:** Console command tests need no changes (default null). Action tests and Livewire tests need `causer:` added.
